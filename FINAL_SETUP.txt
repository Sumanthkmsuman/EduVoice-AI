FINAL SETUP
1. Keep index.html, server.js and package.json together.
2. PowerShell in this folder: npm install
3. Set key: $env:OPENAI_API_KEY="YOUR_API_KEY"
4. Start: npm start
5. Open: http://localhost:3000
6. Keep PowerShell open. Do not double-click index.html.
Do not put your OpenAI API key in the HTML file.
Firebase Authentication Email/Password must be enabled.
Realtime Database rules must allow authenticated access for Student Search and privateChats.
