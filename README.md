# 🎙️ EduVoice AI – AI-Powered Student Voice Assistant

EduVoice AI is a smart student assistant designed to help engineering students manage their academic activities efficiently. It provides class schedules, exam reminders, student communication, and AI-powered learning assistance.

## 🚀 Features

- 🔐 Student Login and Registration
- 👤 Student Profile Management
- 📅 Class Timetable Management
- 📝 Exam Timetable and Reminders
- 🎤 Voice Assistant
- 🤖 AI-Based Subject Explanation
- 💻 Code Explanation
- 📚 Notes and Quiz Generation
- 🔎 Find Students by Phone Number
- 👥 Friends List Management
- 💬 Student Messaging

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Realtime Database
- Node.js
- Express.js
- OpenAI API

## 💻 Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Sumanthkmsuman/EduVoice-AI.git
   ```

2. Navigate to the project folder:

   ```bash
   cd EduVoice-AI
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure your OpenAI API key securely on the server.

5. Start the application:

   ```bash
   npm start
   ```

6. Open your browser:

   ```text
   http://localhost:3000
   ```
